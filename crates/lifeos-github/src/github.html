Agent access

Run lifeos-github --mcp-config | lifeos connection set github to add GitHub under Connections. Store GITHUB_TOKEN in the Vault and choose which agents may use it.

Repository events

Send signed JSON deliveries to /api/plugins/github/hooks/webhook. Enable the webhook and its shared secret in the plugin configuration.

Subscribe to plugin.github.pull_request_merged for completed merges, or select pull request review and review comment events in the repository webhook.

Personal notifications

With the signed webhook configured, sign in to GitHub CLI on the host and run python3 scripts/install-github-notifications.py on macOS. New thread updates appear as plugin.github.notification under Automation → Signals.
